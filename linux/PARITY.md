# Crucible for Linux: parity with the Apple TV app

Every user-visible feature of the Apple TV app (`Sources/CrucibleTV`) and every Linux-only requirement of `docs/LINUX.md`, graded against the Linux client. Audited 2026-11-15 by nine area auditors, each re-checked by an adversarial verifier against the code. The AUR package waits until every row is checked (or marked n/a) and Marcus has used the client for a while.

Each row: `[x]` done, `[ ]` open; **partial** rows say what is missing. Size: S under two hours, M about a day, L several days. Check a row off in the commit that closes it.
